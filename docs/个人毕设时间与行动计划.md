# 个人毕设时间与行动计划

> 当前版本：v0.1.0  · 建立日期：2026-10-20  · 维护平台：GitHub

## 一、暂定研究主题

运动眼镜中的情境化信息交互研究：以业余骑行为初步场景，通过手机网页、ESP32 与低成本显示反馈，验证运动过程中信息出现的时机、数量与反馈方式。

当前不提前锁定最终产品功能。导航、训练状态、环境提醒和镜片适应性都作为待验证方向。
